# РЦА «Русский Восток» — Аналитика и аттестация проводников ДФО

Интерактивная исследовательская и управленческая платформа по кадровому обеспечению активного туризма, моделированию потребности в инструкторах-проводниках и аттестации на базе Регионального центра аттестации «Русский Восток» (ВВГУ + Федерация спортивного туризма России).

## Основные модули

- **Обзор центра (`OverviewSection`)**: институциональный профиль РЦА «Русский Восток», 4 этапа аттестации, действующие программы ДПО (пешеходный, водный, автомобильный туризм), сводная эмпирическая база и раздел FAQ для соискателей.
- **Калькулятор потребности (`CalculatorSection`)**: интерактивная экономико-математическая модель расчёта дефицита кадров $N = \frac{T_{act} \times P_{org}}{G_{size} \times G_{season}} \times K_{season} \times K_{turnover}$, график чувствительности и симулятор закрытия дефицита на 2026–2030 гг.
- **Рынок ДФО (`MarketSection`)**: три профиля рынка, интерактивная карта активности проводников по 8 округам Приморского края (`PrimoryeActivityMap`), пять узких мест, специфика безопасности ДФО, прогноз на 1–3 года и 7 стратегических рекомендаций.
- **Диссертация ВАК 5.2.3 (`DissertationSection`)**: методологический каркас исследования (кандидатский уровень и докторская перспектива), сравнение с IFMGA, научная новизна, положения на защиту и публикационная стратегия.
- **Презентации (`PresentationsSection`)**: академическая защита (18 слайдов, 18 мин), управленческий доклад для Минтуризма (10 слайдов, 12 мин), таймер репетиции и печатный раздаточный лист.
- **SEO и аналитика (`AnalyticsSection`)**: динамические мета-теги, Schema.org JSON-LD, `/robots.txt` и `/sitemap.xml`, статистика визитов, запись ленты поведения пользователей и карта кликов (Click Heatmap).

## Локальный запуск

```bash
npm install
npm run dev
```

Приложение запускается на порту `3000` (`server.ts` + Vite).

## Сборка и запуск в продакшене

```bash
npm run build
npm run start
```
